# 🐍 Snake Game — Python

A simple Snake game built with Python as a learning project. This project helps me practise Python fundamentals while building a playable game.

## 🎮 About the Game

Control the snake, eat food, and increase your score. Avoid hitting the walls or running into your own body!

## ✨ Features

- Simple text-based gameplay in the terminal
- Control the snake using **WASD**
- Eat food (`*`) to earn points
- Track your score
- Game-over message with your final score
- Quit the game by pressing `q`

## 🛠️ Built With

- Python 3
- Python modules: `random` and `os`

## 🚀 Getting Started

### Requirements

- Python 3 installed on your computer

### Run the Game

1. Clone this repository:

   ```bash
   git clone https://github.com/lizenkotech/Snake-Game-Python.git
   ```

2. Open the project folder:

   ```bash
   cd Snake-Game-Python
   ```

3. Run the game:

   ```bash
   python3 Snake.py
   ```

## 🕹️ Controls

| Key | Action |
| --- | --- |
| `W` | Move up |
| `A` | Move left |
| `S` | Move down |
| `D` | Move right |
| `Q` | Quit the game |

Press **Enter** after entering a direction.
